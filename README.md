# Online Store Management

A web application for managing an online tech store, including product listings, shopping cart, and order management.

## Technologies
- HTML5
- CSS3
- JavaScript

## Features
- Product catalog with categories
- Shopping cart
- Order management
- Responsive design

## Getting Started
Open `index.html` in your browser.
